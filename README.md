# 🧮 Calculadora Python

Uma calculadora desenvolvida em Python que permite realizar operações matemáticas por meio de expressões digitadas no terminal.

## Funcionalidades

- Adição (`+`)
- Subtração (`-`)
- Multiplicação (`*`)
- Divisão (`/`)
- Potenciação (`**`)
- Módulo ou resto da divisão (`%`)
- Números positivos e negativos
- Tratamento de erros matemáticos
- Execução contínua até o usuário digitar `sair`

## Tecnologias utilizadas

- Python 3
- Módulos nativos `ast` e `operator`

## Pré-requisitos

Ter o Python 3 instalado na máquina.

## Como executar

1. Clone este repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd calculadora-python
   ```

3. Execute a calculadora:

   ```bash
   python operacao.py
   ```

## Exemplos de uso

```text
Digite a expressão ou 'sair': 10 + 5
Resultado: 15

Digite a expressão ou 'sair': 2 ** 3
Resultado: 8

Digite a expressão ou 'sair': 10 / 0
Erro: Não é possível dividir por zero.
```

Este projeto foi desenvolvido para praticar Python, funções, estruturas de repetição, tratamento de exceções e avaliação controlada de expressões matemáticas utilizando a árvore sintática abstrata (AST).
